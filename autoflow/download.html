Install in Chrome

  1. Download and unzip the file. Keep the unzipped AutoFlow Pro folder somewhere permanent.
  2. Open chrome://extensions. Paste that address into Chrome's address bar.
  3. Turn on Developer mode. Use the switch in the top-right corner of the Extensions page.
  4. Choose Load unpacked. Select the unzipped folder that directly contains manifest.json.
  5. Open AutoFlow Pro. Review the privacy notice and select Agree and continue to activate it.
  6. Sign in with your billing email. Your existing Pro access and billing-management options will be restored automatically.

Chrome may show a standard Developer mode notice for manually installed extensions. This official package is the same version submitted to Google for review.
