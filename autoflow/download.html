Move to the Store version

  1. Open chrome://extensions. If you installed the temporary unpacked package, disable or remove that copy first so two extensions do not control Google Flow at the same time.
  2. Open the official listing. Use the Install AutoFlow Pro button above and select Add to Chrome.
  3. Open AutoFlow Pro. Review the privacy notice and select Agree and continue to activate it.
  4. Sign in with your existing billing email. Use the same email attached to your current AutoFlow Pro subscription.
  5. Do not purchase again. Your existing subscription is unchanged and Pro access will be restored after sign-in.

The new Chrome Web Store item has a different extension ID, so Chrome cannot copy settings or local history from the previous extension automatically.
